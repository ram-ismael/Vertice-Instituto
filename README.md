# Instituto Vértice

Landing page estática e responsiva baseada nas propostas visuais desta pasta. Abra `index.html` através de um servidor local para testar os módulos JavaScript.

```bash
python3 -m http.server 4173
```

Depois visite `http://localhost:4173/`.

## Estrutura

- `index.html`: estrutura semântica, metadados e secções.
- `src/styles.css`: identidade visual e responsividade.
- `src/data.js`: conteúdo configurável.
- `src/main.js`: renderização de cards, filtros, FAQ e menu.
- `assets/`: imagens WebP optimizadas e favicon.
- `.github/workflows/deploy.yml`: publicação com GitHub Actions.
- `PUBLICAR-GITHUB.md`: instruções de publicação e partilha.

Este é um projecto conceptual para portfólio. Instituição, pessoas, programas, testemunhos, métricas e notícias são demonstrativos. O portal apresentado é uma pré-visualização visual, sem acesso real. O conteúdo deve ser validado antes de uso institucional. As propostas `vertice-desktop-navbar-direita.png`, `vertice-tablet.png` e `vertice-mobile.png` continuam guardadas como referência de design.
